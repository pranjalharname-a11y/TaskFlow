# TaskFlow

## About

TaskFlow is a Project and Task Management application.

It allows users to:
- Login
- Create and manage projects
- Create and manage tasks
- Track task status and priority
- Search and filter tasks
- View project and task information
- View dashboard statistics

## Technologies Used

### Frontend
- React.js
- React Router
- Axios
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MySQL
- bcrypt

## Main Features

- User Login
- Dashboard
- Project Management
- Task Management
- Add, Edit and Delete Projects
- Add, Edit and Delete Tasks
- Task Search
- Status Filter
- Priority Filter
- Responsive UI
